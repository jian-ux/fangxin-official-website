# 小黎自动挥手

直接使用原始 welcome.mp4 第 21–84 帧（从 0 计数）的连续动作，不拆分人物。保留 24fps，挥手约 2.67 秒，停留 5 秒，每轮约 7.67 秒；循环和停顿均在同一 WebP 内，不在每轮切换图片 URL。

- 气泡位置及大小固定；进入页面 200 毫秒后，文字每隔 150 毫秒依次渐显，完成后保持显示，不随挥手重播。减少动态效果时直接显示。
- 页面可见且头像进入视口时自动播放；离开视口、标签页隐藏、减少动态效果或加载失败时显示静态图。
- 去掉原来的交叉淡化，避免两个手势叠加。暂停帧与首帧、备用图共用同一份编码图像数据，不重复压缩；本地 Pillow 验证解码像素差为 0。
- 画布 480×480，原片缩至 416×416，四周留 32px，保留圆形、完整叶子和原片浅底。
- 动图 1,120,376 字节（约 1.07 MiB），比原 8,031,458 字节缩小约 86%；使用质量 82 的有损压缩，保持帧率。
- 输出为 assets/xiaoli-greeting.webp 和 assets/xiaoli-greeting-poster.webp。本目录旧分层 PNG 不参与页面构建。

## 重建命令（仓库根目录，需要本地 FFmpeg）

```powershell
node tools/build-xiaoli.mjs
```

生成脚本检查首帧为完整画布，再复用该帧作为五秒停顿和静态备用图；测试验证帧数据一致、无混合、循环时长和自动播放回退。
